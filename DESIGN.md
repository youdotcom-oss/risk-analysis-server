## Overview

Calm, precise, and analyst-grade. The briefing reads like a well-built console
page: mostly neutral, one accent, status conveyed by a single tag. Elevation is
a hairline border, never a heavy shadow. Nothing decorative — every element
carries information.

## Color

- **Surface and text first.** White surface on an off-white page, near-black
  text, one gray for secondary. Most of the document is neutral.
- **Brand (`brand`) is a spotlight.** Used for the header rule and links. One
  accent moment per report.
- **Severity colors carry state.** `severity-low` (green), `severity-medium`
  (amber), `severity-critical` (red) drive the severity tag and the header
  accent. Amber is darkened from a pure yellow so it clears contrast on the
  white surface; severity is always paired with text, never color alone.

## Typography

One system stack — no web fonts (the report renders inside a sandboxed
iframe). Headings are semibold; body is 14/22 for dense, readable analysis;
captions are for metadata (dates, source counts).

## Do's and Don'ts

- Do keep severity as one tag plus one accent line — never a colored page.
- Don't use color for decoration; status and links only.
- Do use the hairline border and generous padding for hierarchy.
- Don't add shadows heavier than a 1px-offset lift.
- Do keep the document self-contained: inline CSS, no external requests.
